# Golden Scene S04 — `CIENTÍFICAMENTE`

This directory is the executable contract for the first T07 golden-scene reconstruction.

## Source boundary

- Source frames: `145..215` (`end_frame_exclusive=216`).
- Visual duration authority: `71 / 30 = 2.366666… s`.
- Source media, clean frames and renders stay in canonical Drive; public Git stores code, timing, contracts and hashes only.
- The exact source font, original After Effects project, original keyframe curves and isolated SFX stem are unknown.

## Renderer modes

`procedural` is the clean-runner structural fixture. It proves composition registration, frame-driven motion, captions and deterministic synthesized impact audio. It grants no source-fidelity authority.

`image-sequence` consumes `public/<plateFolder>/0001.png..0071.png`, intended for a locally materialized clean plate. Because that frame sequence already contains the measured source reframe, `plateIncludesEditorialReframe=true` prevents double animation.

## Promotion boundary

A green render becomes `STRUCTURAL_RENDER_EXECUTED`. It becomes `FIDELITY_VALIDATED` only after source-bound nine-dimensional diff, defect adjudication and human review.
