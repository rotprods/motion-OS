# MOTION.OS Wave Protocol

Every major system change is evaluated on two axes:

1. **Convergence** — improve the current canonical master without regressions.
2. **Generalization** — rebuild an unseen brief from zero under radically different visual grammars.

A system change is not considered broadly successful merely because it improves one editorial master.

## Generalization fixture truth
Fast fixtures may use reduced source fps for search. They measure routing/diversity, not production-release quality. Production benchmark runs must use qualified renderer paths and authoritative semantic QA.
