# Architecture Gap Analysis

## Current truth
The architecture is considerably more mature than the visual production path.

## Gap
The primary gap is not another graph abstraction. It is converting the control plane into consistently professional motion output using:
1. real assets,
2. real renderer runtime,
3. authoritative semantic QA,
4. graph-native repair,
5. diverse benchmarks.

## Strategic constraint
Until the vertical slice clears professional visual gates, architecture work receives lower priority unless it directly removes a blocker.
