# Wave Protocol v2

Each major engine change must face two independent tests.

## Convergence lane
Improve the canonical working master. Use isolated defect clusters, materially different repair branches, regression protection and promote/rollback.

## Generalization lane
Use an unseen brief. Generate at least four visual grammars from zero. A family must differ in more than palette: layout, typography, materiality and motion grammar must change.

## Interpretation
- Convergence pass alone can mean overfitting.
- Generalization pass alone can mean shallow breadth.
- The system matures only when both improve under the same engine version.
