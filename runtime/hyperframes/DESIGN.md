# HyperFrames runtime fixture — visual identity

## Purpose
Deterministic technical runtime proof only. This is not a creative-quality benchmark or production master.

## Style Prompt
Minimal dark technical composition with a near-black canvas, warm off-white typography, simple depth separation and restrained geometric motion so frame capture is visually non-empty and deterministic.

## Colors
- Canvas: `#090909`
- Primary text: `#F5F5F0`
- Secondary surface: `#181818`
- Accent: `#FF6B35`

## Typography
System sans-serif fallback stack only for portability in the clean runner. Font identity is not part of this runtime proof.

## Motion
Short deterministic opacity/translate/scale changes. No random values, no infinite repeats, no asynchronous timeline construction.

## What NOT to Do
- no remote media assets;
- no runtime randomness;
- no infinite animation loops;
- no claim that this fixture proves creative quality;
- no container-duration-only timing authority.
