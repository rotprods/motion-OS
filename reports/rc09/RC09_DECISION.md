# RC09 structural convergence decision

## Baseline
RC06 remains the prior working master.

## Search
RC09 used a structural search rather than additive overlays. Four exploration branches were rendered:
- A: asymmetric hero/editorial topology
- B: camera/depth corridor + foreground occlusion
- C: kinetic-type-led composition with reduced hero dependency
- D: modular split-field system

A second exploit pass produced **RC09E**: asymmetric editorial topology using the real coin hero rather than placeholder geometry, while restoring the canonical narrative (`they are selling / REBELLION → MOVEMENT → SYSTEM → MOTION SYSTEM`).

## Technical invariants
- 1080×1920
- 30 fps source render for RC09E
- final duration: 10.000 s
- AAC audio preserved from RC06
- validated RC06 transition region 6.65–7.50 s is spliced from the baseline master rather than redesigned

## Evidence
Visual review finds RC09E materially improves hero framing, negative-space discipline, SYSTEM hierarchy, final-frame structure and professional finish compared with RC06, while retaining the established narrative.

The earlier A branch was rejected despite cleaner structure because it drifted from the canonical copy. B was rejected because the dark corridor produced severe boundary discontinuity into the protected beige transition. C/D demonstrated structural diversity but were not preferred on asset/finish grounds.

## Decision
**PROMOTE RC09E TO WORKING MASTER.**

This is a working-master promotion, not production release. Full-video authoritative temporal semantic QA is still unavailable, so release remains BLOCKED.
