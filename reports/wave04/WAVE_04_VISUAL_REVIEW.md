# Wave 04 Visual Review

Brief: climate-intelligence satellite network. Beats: SEE → PREDICT → ACT.

## Orbital Mission Control
Strongest temporal/system metaphor of the four. Radar/orbit language is immediately distinct, dark technical palette and moving scan establish a genuine mission-control grammar.

## Editorial Cartography
Distinct paper/topographic system with location markers and serif hierarchy. Strong domain fit; restrained rather than cinematic.

## Kinetic Data Sculpture
Most abstract/data-driven branch. Particle topology and bar structures create a different grammar, though current fixture remains intentionally simple.

## Chrome Fashion Future
Most materially different art direction: metallic orb, fashion-editorial typography, silver field. Demonstrates style routing beyond technical/editorial defaults.

## Decision
Wave passes **diversity discovery** but not production quality. None of these fixtures are release candidates. Use them as evidence that unseen-brief routing can generate distinct design systems; next step is production-render qualification and authoritative temporal QA.
